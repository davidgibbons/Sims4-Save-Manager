    Locations

      Where this app keeps copies you can restore later. Keep this outside OneDrive or iCloud.
      Changing this location does not move existing copies.
      
        
      
        
      
          
      Automatic backups
      
          
          
      Starts checking as soon as you turn it on. The first copy starts after about 10–15 seconds without file changes; later saved changes create new copies. Copying large saves takes longer. Older backups stay available.
      
          
      Keep this app running. You can close its window: it stays in the system tray (Windows) or menu bar (Mac). Choosing Quit stops automatic backups. Nothing runs while the computer is asleep. No background service is installed.
      
          
          
      
          
      Checking automatic backup status…
      
          
      
          
      
          
      Automatic copies appear in Saved games → Backups, labeled Automatic backup. This copies saved files; it cannot save unsaved progress in The Sims 4.
